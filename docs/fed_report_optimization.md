## 技术细节

### 变化量计算
- 使用绝对差值（百分点）而非百分比
- 公式：`变化量 = 当前值 - 昨日值`
- 阈值：变化 ≥ 0.01pp 才显示具体数值，否则显示"➡️"

### 排序逻辑
- 有变化的国家按变化量绝对值排序（排在前）
- 无变化的国家按固定顺序（CN, US, EU, JP, CA, AU）

### 图标说明
- 📈 上升（利率增加）
- 📉 下降（利率降低）
- ➡️ 无变化（变化 < 0.01pp）
- [首次] 首次获取数据
- [获取失败] 数据获取失败
